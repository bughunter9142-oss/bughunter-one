# Installation guide

BugHunter One supports Python 3.10+ on Windows, Linux/Kali, and macOS. Install from a checkout with `python -m pip install -e .`, or use `python -m pip install .` for a standard installation. For CI/lint/build tools use `python -m pip install -e ".[dev]"`.

Verify the installed commands with `bughunter-one --help`, `bughunter-dashboard --help`, and `bughunter-one --version`.
